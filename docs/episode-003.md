# «Третий гайд»

Вертикальный мультфильм о первой публикации Ильи. После ночной смены он покупает очередной гайд и закрывает его на первой странице. Когда у коллеги одна коробка оказывается в накладной дважды, у Ильи впервые появляется конкретный зритель. Он пробует записать объяснение, открывает курс «AI для брендов», вырезает приветствие и отправляет в канал полезный разбор.

Илья, Лена и история их канала вымышлены. Тысяча и 2 300 подписчиков появляются у Ильи спустя недели и серию публикаций. Цифры относятся к сюжету. В сцене курса использован реальный мобильный экран Академии. [Карточка курса](https://sprosi-ai-mockup.vercel.app/app/courses/ai-video/)

## Исходники и экспорт

Композиции зарегистрированы в `src/film003/Film.tsx`. Рисунки, прозрачные позы и восемь фаз шага лежат в `public/episodes/episode-003/`. Фазы и выражения лица задаёт код в `src/film003/`. Реплики и монтажные интервалы находятся в `src/episodes/episode-003-voice.json` и `episode-003-cuts.json`. Синхронизация субтитров и рта вычисляется отдельно по каждой голосовой дорожке.

Готовые композиции рассчитаны на 1296 кадров, 24 кадра в секунду, 1080 × 1920. Для локального экспорта нужны Node.js, Python с NumPy и SciPy, FFmpeg и браузер Remotion.

```sh
npm ci
python -m pip install numpy scipy
node scripts/generate-voice-variants.mjs --provider=elevenlabs src/episodes/episode-003-voice.json
python scripts/mix-episode-003.py elevenlabs
npx remotion render src/index.tsx NightShiftElevenLabs out/tretiy-gaid-elevenlabs.mp4 --codec=h264 --crf=18
```

Для варианта Google Translate TTS выполните `python scripts/record-google-public-003.py`, затем `python scripts/mix-episode-003.py google-public` и рендерите `NightShiftGoogle`. Для Gemini используются `--provider=google`, `mix-episode-003.py google` и композиция `NightShiftGemini`. В этой сессии Gemini вернул HTTP 402 из-за исчерпанного баланса проекта.

Через GitHub Actions сначала запустите `render-cartoon.yml` с параметром `episode-003-elevenlabs`. Для экспорта выберите `episode-003-render` и передайте ID успешного запуска записи в `dialogue_run`. Рендер использует сохранённые реплики ElevenLabs, чтобы повторный экспорт не расходовал лимит синтеза.
